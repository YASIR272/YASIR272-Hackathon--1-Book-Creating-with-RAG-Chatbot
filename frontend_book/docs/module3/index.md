# Module 3: The AI-Robot Brain (NVIDIA Isaac™)

Welcome to Module 3 of the ROS 2 for AI Developers book. This module focuses on NVIDIA Isaac, the AI-powered robotics platform that enables advanced perception and navigation for humanoid robots.

## Learning Objectives

By the end of this module, you will be able to:

- Understand the fundamentals of NVIDIA Isaac Sim for photorealistic simulation
- Generate synthetic data for perception training using Isaac Sim
- Implement hardware-accelerated visual SLAM (VSLAM) with Isaac ROS
- Build perception pipelines for robot navigation
- Plan and execute trajectories for bipedal humanoid motion using Nav2
- Integrate AI-driven control systems for autonomous navigation

## Module Structure

This module is organized into three main chapters:

1. **[NVIDIA Isaac Sim Basics](./chapter1-isaac-sim-basics)** - Learn about photorealistic simulation, synthetic data generation, and environment setup
2. **[Isaac ROS & VSLAM](./chapter2-isaac-ros-vslam)** - Explore hardware-accelerated visual SLAM, perception pipelines, and navigation
3. **[Path Planning with Nav2](./chapter3-path-planning-nav2)** - Master bipedal humanoid motion, trajectory planning, and AI-driven control

Let's begin by exploring the fundamentals of NVIDIA Isaac Sim in the next chapter.
